📋 SETUP INSTRUCTIONS
================================================================================

1. ENVIRONMENT SETUP:
   - Copy .env.example to .env
   - Configure DATABASE_URL
   - Configure JWT_SECRET
   - Configure API_PORT (default: 3001)

2. DATABASE MIGRATION:
   cd database
   npx prisma migrate dev --name phase_2_1_complete
   npx prisma generate

3. INSTALL DEPENDENCIES:
   Backend:  cd apps/api && npm install
   Frontend: cd apps/web && npm install

4. START SERVICES:
   Backend:  cd apps/api && npm run dev
   Frontend: cd apps/web && npm run dev

5. SEED PERMISSIONS (Optional):
   POST http://localhost:3001/api/v1/permissions/seed

6. ACCESS APPLICATION:
   API:      http://localhost:3001
   API Docs: http://localhost:3001/api/docs
   Frontend: http://localhost:3000
